# 🤝 Вклад в проект

Спасибо, что хотите улучшить **All about Roblox**! Приветствуются исправления ошибок, новые гайды и примеры скриптов.

## 🚀 Как предложить изменения

1. Сделайте **Fork** репозитория.
2. Создайте ветку: `git checkout -b fix/опечатка-в-разделе-3`.
3. Внесите изменения и сделайте коммит с понятным сообщением.
4. Откройте **Pull Request** с описанием того, что и зачем изменили.

## 📝 Правила для текстов

- Пишем на **русском языке**, простым и понятным языком.
- Технические термины (Part, Script, Humanoid…) не переводим.
- Один раздел = один файл в `docs/`, именование: `NN-название.md`.
- Ссылки между разделами — относительные.

## 💻 Правила для скриптов

- Каждый скрипт начинается с **шапки-комментария**: что делает, куда вставить, что подготовить.
- Код с **аннотациями типов** Luau там, где это уместно.
- Имена переменных и функций — понятные, на английском.
- Пример должен **работать из коробки** после вставки в Studio (с описанной подготовкой).
- Никаких читов, эксплойтов и обхода правил Roblox — такие PR закрываются сразу.

## 🐛 Нашли ошибку?

Откройте **Issue**: укажите раздел/файл, что не так и как должно быть.
