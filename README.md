## 💻 Примеры скриптов

Готовые скрипты на Luau с подробными комментариями — просто скопируйте в Roblox Studio.

| Скрипт | Что делает | Куда вставить |
|--------|------------|---------------|
| [`leaderstats.lua`](scripts/leaderstats.lua) | Таблица лидеров с монетами | ServerScriptService |
| [`collect-coins.lua`](scripts/collect-coins.lua) | Сбор монет при касании | ServerScriptService |
| [`day-night-cycle.lua`](scripts/day-night-cycle.lua) | Плавная смена дня и ночи | ServerScriptService |
| [`teleport-pad.lua`](scripts/teleport-pad.lua) | Телепорт-площадки | ServerScriptService |
| [`double-jump.lua`](scripts/double-jump.lua) | Двойной прыжок | StarterPlayerScripts (LocalScript) |

Как пользоваться — в [`scripts/README.md`](scripts/README.md).
