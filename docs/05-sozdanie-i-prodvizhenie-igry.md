# 5. Создание и продвижение игры

Как превратить идею в игру, в которую будут играть, и как на этом заработать.

## 💡 С чего начать: выбор идеи

Для первой игры выбирайте **простую механику**:

- обби (полоса препятствий);
- тайкун («построй базу»);
- симулятор кликера;
- «выживание на острове»;
- гонка с чекпоинтами.

> 🎯 Правило: лучше законченная маленькая игра, чем заброшенный «проект мечты».

## 🎮 Основы геймдизайна

1. **Первые 60 секунд решают.** Игрок должен сразу понять, что делать и получить удовольствие.
2. **Обучайте через игру**, а не стеной текста: подсказки, стрелки, пробные препятствия.
3. **Цикл вовлечения:** действие → награда → улучшение → новое действие. Например: собрал монеты → купил ускорение → собираешь быстрее.
4. **Прогрессия:** уровни, ранги, открытия — причина вернуться завтра.
5. **Социальность:** лидерборды, торговля, совместные задания удерживают игроков.
6. **Тестируйте на людях** — друзья и DevForum найдут проблемы, которые вы не видите.

## 💰 Монетизация

| Способ | Как работает |
|--------|--------------|
| **Game Pass** | разовая покупка бонуса (VIP, x2 монеты) |
| **Developer Products** | повторяющиеся покупки (пачка монет, энергия) |
| **Private Servers** | платные приватные серверы |
| **Paid Access** | вход в игру за Robux (для новичков не рекомендуется) |

Честная монетизация = косметика и удобства, а не «плати, чтобы победить». Игроки чувствуют жадность и уходят.

```lua
-- проверка Game Pass на сервере
local MarketplaceService = game:GetService("MarketplaceService")
local VIP_PASS_ID = 0000000 -- замените на ID вашего пасса

local function hasVIP(player: Player): boolean
	local ok, owns = pcall(function()
		return MarketplaceService:UserOwnsGamePassAsync(player.UserId, VIP_PASS_ID)
	end)
	return ok and owns
end
```

## 🏦 DevEx: Robux → реальные деньги

**Developer Exchange** позволяет обменять заработанные Robux на доллары. Основные условия:

- возраст 13+;
- верифицированный аккаунт и налоговая информация;
- Robux заработаны легально (продажи в играх, а не куплены/переведены);
- минимальная сумма к выводу — 30 000 Robux.

Актуальные условия всегда проверяйте на официальной странице DevEx.

## 📣 Продвижение

- **Иконка и миниатюра** — первое, что видит игрок. Сделайте их яркими и читаемыми.
- **Название и описание** — с ключевыми словами, по которым игру будут искать.
- **Обновления** — регулярные апдейты поднимают игру в рекомендациях.
- **Сообщество** — группа Roblox, DevForum, соцсети, видео блогеров.
- **Реклама Roblox** — Sponsored Experiences и User Ads (когда появится бюджет).

## 📈 Аналитика

На [create.roblox.com](https://create.roblox.com) → **Creator Dashboard** → **Analytics** доступны:

- DAU/MAU — дневная и месячная аудитория;
- удержание (Retention) — сколько игроков возвращается;
- средний сеанс;
- конверсия в покупки.

Следите прежде всего за **удержанием D1** — если игроки не возвращаются на следующий день, чините первую сессию.
