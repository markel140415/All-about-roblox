# 2. Первые шаги в Roblox Studio

**Roblox Studio** — бесплатный движок, в котором создаются все игры Roblox. В этом разделе — путь от установки до первого опубликованного «плейса».

## ⬇️ Установка

1. Создайте аккаунт на [roblox.com](https://www.roblox.com) (если его ещё нет).
2. Откройте [create.roblox.com](https://create.roblox.com) и скачайте Roblox Studio.
3. Установите и войдите под своим аккаунтом.

**Системные требования** скромные: Windows или macOS, 4+ ГБ ОЗУ, обычная видеокарта. Linux официально не поддерживается.

## 🖥️ Интерфейс: главные окна

После запуска выберите шаблон **Baseplate** — пустой мир с плитой-полом.

| Окно | Где | Зачем |
|------|-----|-------|
| **Explorer** | View → Explorer | Дерево всех объектов игры (сервисы, детали, скрипты) |
| **Properties** | View → Properties | Свойства выбранного объекта (размер, цвет, материал…) |
| **Toolbox** | View → Toolbox | Библиотека бесплатных моделей, звуков, декалей |
| **Output** | View → Output | Консоль: ошибки и `print()`-сообщения |
| **Command Bar** | View → Command Bar | Быстрое выполнение команд Luau |

## 🧱 Базовые объекты

- **Part** — «кирпичик», базовый строительный блок (Home → Part). Бывает Block, Sphere, Cylinder, Wedge, CornerWedge.
- **Model** — группа объектов. Персонаж игрока — тоже Model.
- **Terrain** — ландшафт: горы, вода, пещеры (Home → Terrain Editor).
- **Material / Color** — внешний вид детали задаётся в Properties.

**Полезные горячие клавиши:**

| Клавиша | Действие |
|---------|----------|
| `W` / `E` / `R` | Двигать / Вращать / Масштабировать |
| `Ctrl+D` | Дублировать |
| `Ctrl+G` | Сгруппировать в Model |
| `F` | Сфокусировать камеру на объекте |
| `F5` | Запустить тест игры (Play) |

## ⚙️ Свойства, которые нужно знать

- **Anchored** — «закреплена ли деталь». Незакреплённые детали падают под действием гравитации. Пол и стены почти всегда делают Anchored.
- **CanCollide** — можно ли столкнуться с деталью.
- **Transparency** — прозрачность (0 — видимая, 1 — невидимая).
- **Name** — имя объекта; именно по имени скрипты находят объекты. Давайте объектам осмысленные имена без пробелов.

## ▶️ Тестирование

- **Play (F5)** — запуск в обычном режиме.
- **Test → Clients and Servers** — запуск нескольких окон для проверки мультиплеера.
- **Stop (Shift+F5)** — остановка теста.

## 📦 Публикация игры

1. **File → Game Settings** — придумайте название и описание.
2. **File → Publish to Roblox** (`Alt+P`) — загрузка на сервер.
3. Откройте [create.roblox.com](https://create.roblox.com) → ваши креации → включите публичный доступ (Make Public).

Готово — в вашу игру уже могут играть другие люди!
